# CASULO — REVOLUTION CLOSURE GOAL

**Data de preparação:** 2026-08-14  
**Autor da visão:** Guilherme Moura Fernandes  
**Destino:** Codex trabalhando sobre o repositório real `Casulo`  
**Estado final pretendido:** `READY_FOR_GUILHERME_CASULO_BETA_HUMAN_PROOF`

## Missão

Este pacote fecha, em uma única sequência de engenharia, os nove vazios entre o
Casulo atual e a primeira prova humana integral do produto:

1. Guia com continuidade, inteligência relacional e química de trabalho;
2. geração que verifica o significado do pedido, e não apenas compilação;
3. Linguagem T como camada soberana da criação;
4. motor Casulo com adaptação, especialistas e treino first-party;
5. Semantic Multiverse validado como arquitetura de working set;
6. VM apresentada como produto de um clique;
7. voz duplex como interface principal;
8. agentes que funcionam, são auditáveis e reabrem fora do laboratório;
9. segurança proporcional à autonomia.

O resultado não é release comercial, Live USB ou prova de superioridade
universal. É um **candidato integrado para Guilherme usar livremente por horas**, com
snapshot, recuperação, notas e evidências suficientes para decidir o que mudar.

## Como usar

1. Coloque este ZIP no mesmo contexto do repositório real.
2. Entregue `14_PROMPT_GOAL_CODEX.md` como prompt principal.
3. O Codex lê todos os `AGENTS.md`, README, locks, manifests e estados reais
   antes deste pacote.
4. O Codex executa RC0–RC13 sem pedir confirmação entre sprints, exceto quando
   houver consentimento obrigatório, acesso físico ou mudança irreversível.
5. Nenhum gate pode ser aprovado por fixture, mock ou resposta preparada no
   caminho owner final.
6. O último ato automatizado é selar a VM e entregar o runbook. A prova humana
   pertence somente a Guilherme.

## Regra anti-fingimento

O Codex deve preferir `IN_PROGRESS_CHECKPOINTED` ou um bloqueio explícito a
declarar sucesso quando faltar voz física, treino real, execução externa,
isolamento, evidência semântica ou avaliação humana. “Funciona” sempre significa
que existe artefato, comando, receipt e reprodução — não somente código escrito.
