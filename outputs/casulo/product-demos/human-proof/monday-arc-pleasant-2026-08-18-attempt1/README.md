# Casulo ARC-9 — interface owner fluida

Abra `START_CASULO_ARC9.vbs` por duplo clique.

Esta tentativa preserva o release T85 e executa o checkout owner local no
perfil de inspeção. A interface oferece presença imediata, aceita texto durante
o carregamento, apresenta tokens reais conforme chegam e move a produção após
`CONFIRMO` para um job cancelável em background.

O caminho principal mostra conversa, criação e estado vivo. Universos, rota,
memória, snapshot, restore, exportação e cancelamento ficam em **Mais**.
Milestones de criação exigem SHA-256 de um artifact ou receipt real; nenhuma
porcentagem ou ETA é fabricada.

Voz continua bloqueada até consentimento literal. Cloud permanece
`RELEASE_LOCKED`, guest network OFF e USB/block devices proibidos. Esta é uma
superfície para prova humana, não aprovação de química, voz, design final ou
release comercial.
