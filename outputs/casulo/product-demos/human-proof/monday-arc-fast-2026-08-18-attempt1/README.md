# Casulo ARC — inspeção rápida do IntentTwin

Abra `START_CASULO_ARC.vbs` por duplo clique.

O perfil usa o checkout atual e preserva o release T85 selado. Conversa comum
mantém o Qwen local quente e mostra deltas reais. No comando `:criar`, o Casulo:

1. reconstrói observações e hipóteses;
2. faz no máximo uma pergunta material;
3. abre o espelho visual do `IntentTwin`;
4. aguarda `CONFIRMO` literal;
5. compila requisitos para a autoridade T;
6. bloqueia materialização se qualquer HARD estiver `FAIL` ou `UNKNOWN`.

O modelo não cria grants nem confirmação. Cloud permanece `RELEASE_LOCKED`, a
rede guest fica OFF e voz física continua sujeita a consentimento literal.

Esta é inspeção de produto em desenvolvimento, não release comercial, prova de
compreensão universal ou benchmark.
