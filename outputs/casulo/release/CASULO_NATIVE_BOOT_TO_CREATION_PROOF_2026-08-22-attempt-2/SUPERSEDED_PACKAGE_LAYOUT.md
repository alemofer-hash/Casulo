# Pacote superseded

O conteúdo e a assinatura desta tentativa são válidos, mas o ZIP preservou os
launchers em layout plano; por isso eles dependiam da árvore original e não
formavam um handoff autocontido. O pacote permanece preservado como evidência e
não deve ser usado para inspeção.

A tentativa seguinte inclui a árvore `release/` e os helpers `os/tools/`
necessários para iniciar a prova a partir do diretório extraído, sem embutir o
modelo owner.
