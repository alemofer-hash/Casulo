# Casulo Native owner-alpha preview

Este artefato UEFI passou três boots como USB virtual read-only. Ele contém renderer Stark + Jobs, decoder limitado, TCAP, system pack, ABI neural e journal.

**Não é ainda a primeira conversa Native.** O Qwen não executou: o runtime local é PE/COFF Windows e o loader/grafo freestanding não existe. Não apresente o evento de token do ABI como inferência neural.

Nenhuma mídia física foi gravada. A seleção do pendrive e a confirmação destrutiva pertencem a um gate humano posterior.
