# Interlocution research track

Private, append-only research implementation for the live Interlocution Theorem
instance. It is deliberately outside owner/public/native product entrypoints.

The track uses the existing T/2.0 parser, semantic analyzer, typed IR, module
graph, TCAP builder and Rust runtime. Python transports validated inputs and T
observables; it is not allowed to reconstruct an affirmative T decision.

No network, Cloud, USB, external API or physical-energy claim is part of this
track.
