## Finalidade

Este pacote conduz o Casulo do Product Alpha estrutural até sua primeira versão realmente generativa dentro de uma máquina virtual.

O salto desta etapa não é beleza, velocidade ou completude. É tornar real esta experiência:

> Guilherme conversa com o Guia como conversa com um amigo intelectualmente brilhante, quente e direto; os dois desenvolvem uma ideia em conjunto, o Casulo gera um agente inédito, mostra sua formação, aceita interrupções e correções e o materializa.

“Science bros” significa química humana de trabalho: calor, confiança, ritmo, curiosidade compartilhada e prazer em construir. Não restringe o assunto à ciência.

## Limite desta etapa

Esta etapa termina quando:

1. o motor owner é estocástico e generativo, não uma referência determinística;
2. o fluxo conversa -> intenção -> T -> simulação -> agente funciona dentro da VM;
3. a estética inicial Stark + Jobs está presente como interpretação provisória;
4. Guilherme recebe uma VM segura para usar livremente, observar e registrar mudanças desejadas;
5. o projeto para em `READY_FOR_GUILHERME_GENERATIVE_VM_INSPECTION`.

Não construir, formatar, gravar ou testar dispositivo externo. Essa será outra etapa, condicionada a mídia externa explicitamente escolhida e com capacidade utilizável estritamente maior que 80 GiB.
