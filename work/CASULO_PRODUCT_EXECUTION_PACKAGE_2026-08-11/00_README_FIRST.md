# CASULO — PRODUCT EXECUTION PACKAGE

**Data de congelamento:** 2026-08-11  
**Direção:** produto local-first, voice-first e exportável  
**Autor da visão:** Guilherme Moura Fernandes  
**Destinatário:** Codex operando sobre o repositório real `Casulo`

## O que este pacote faz

Este pacote substitui a direção de pesquisa orientada a benchmarks pelo desenvolvimento do Casulo como produto. Ele contém:

1. constituição do produto e experiência;
2. arquitetura completa em camadas;
3. matriz de lacunas conhecidas da Linguagem T;
4. lógica e matemática operacional;
5. dependências e requisitos de instalação;
6. decisão formal de encerrar a campanha científica como gate;
7. GOAL autônomo para o Codex;
8. plano de implementação separado em sprints;
9. critérios de aceitação e testes;
10. referências visuais do boot e dos 12 estados de criação.

## Como usar

1. Anexe o ZIP deste pacote ao mesmo contexto em que o repositório `Casulo` estiver disponível.
2. Entregue ao Codex o arquivo `07_GOAL_CODEX_CASULO_PRODUCT.md` como prompt principal.
3. O Codex deve ler primeiro `Casulo/AGENTS.md` e `Casulo/README.md`.
4. Depois, deve ler este pacote integralmente, na ordem numérica.
5. `08_SPRINT_PLAN.md` define a sequência. Nenhuma sprint pode ser declarada pronta sem os gates de `09_ACCEPTANCE_TESTS.md`.

## Fonte de verdade e limites deste pacote

O repositório completo não estava montado durante a preparação. A análise usou:

- o dossiê auditado do commit histórico `df12e916c90d9bd2b966326275dc191573f38abd`;
- o snapshot mínimo de `src/casulo/t`;
- as especificações T 1.0, CrisálidaIR 0.1, Metamorfose Graph 0.1 e Workspace T 0.1;
- o GOAL científico anterior;
- a visão de produto definida com o usuário nesta conversa.

Por isso, toda afirmação sobre uma lacuna do código está marcada como:

- `KNOWN_HISTORICAL_GAP`: comprovada no snapshot auditado;
- `REPO_AUDIT_REQUIRED`: precisa ser confirmada no repositório atual;
- `NEW_PRODUCT_REQUIREMENT`: capacidade nova que não existia na especificação histórica.

O Sprint 0 precisa atualizar a matriz sem apagar o histórico.
