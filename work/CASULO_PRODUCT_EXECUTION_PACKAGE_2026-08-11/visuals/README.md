## Regras

- referências conceituais, não pixel specs;
- nenhum elemento decorativo sem estado semântico correspondente;
- não copiar macOS, Windows ou HUD cinematográfico existente;
- preservar preto/grafite, marfim, âmbar e azul profundo;
- a mesma criação amadurece; ela não é regenerada como objeto diferente a cada estado;
- a voz e a presença têm prioridade sobre efeitos visuais;
- a interface precisa funcionar sem mouse no caminho principal;
- texto nas imagens é ilustrativo e deve ser localizado pelo produto.
